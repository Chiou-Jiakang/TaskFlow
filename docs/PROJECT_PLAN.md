# TaskFlow｜專案開發計畫

## 專案目標

建立具備資料持久化、角色權限管理、
多人協作及即時同步功能的全端專案管理平台。

| ---- | ------------------------ | ------ |
| M0   | 專案與 Git 初始化        | 已完成 |
| M1   | 網站骨架與基本介面       | 未開始 |
| M2   | SQLite 與專案 CRUD API   | 未開始 |
| M3   | 使用者註冊與登入         | 未開始 |

| M10  | 測試、安全檢查及 Release | 未開始 |

## 開發原則

1. 每個開發批次同步更新相關文件。
2. 定期完成 Git Commit 與 Push。
3. 所有程式碼以 VS Code 管理。
4. 優先確保架構、資料與 API 一致性。
5. 開發日誌與測試紀錄採累積式維護。
6. 未通過測試的功能不得宣告完成。

## 完成標準

每個 Milestone 必須具備：

- 可確認的開發成果
- 必要的測試與驗證
- 更新完成的相關文件
- 可追溯的 Git Commit
- 已確認的遠端同步狀態
